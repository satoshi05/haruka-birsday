# OUR DAYS — Birthday Memory Book

スマートフォンで二人の思い出を振り返る、誕生日プレゼント用のプライベートWebサイトです。

## Media safety

- `assets/photos/raw/` と `assets/videos/raw/` は原本保管場所です。
- raw素材は削除・変更・上書きせず、常に読み取り専用データとして扱います。
- 選定・変換が必要な素材は `selected/` や生成用ディレクトリへコピーします。
- raw素材は `.gitignore` によりGit管理対象外です。

## Current phase

現在はSTEP 1（プロジェクト構造の作成）まで完了しています。素材投入後、解析・選定・レポート作成を行い、確認を受けてからWebサイト実装へ進みます。
